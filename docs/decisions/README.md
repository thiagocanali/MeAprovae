# Registro de decisões arquiteturais (ADR)

Este diretório registra decisões relevantes de produto, arquitetura e operação.

## Como registrar

Criar um arquivo por decisão, usando o padrão:

`NNNN-titulo-curto.md`

Estrutura recomendada:
- Status: proposta, aceita, substituída ou rejeitada.
- Contexto e problema.
- Opções consideradas.
- Decisão.
- Consequências positivas e negativas.
- Data e responsáveis.

Decisões aceitas não devem ser editadas para apagar seu histórico. Quando uma decisão mudar, criar uma nova ADR que a substitua.
